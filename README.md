# Media-Pile

Organize sua pilha de mídia de forma automática e eficiente.

## 📦 Funcionalidades

- Organiza imagens, vídeos e áudios por tipo e data
- Renomeia arquivos com padrões configuráveis
- Detecta e remove duplicatas
- Gera relatórios de organização
- Suporte a múltiplos formatos de mídia

## 🚀 Instalação

```bash
git clone https://github.com/MiguelReis944/Media-Pile.git
cd Media-Pile
pip install -r requirements.txt
```

## 🛠️ Uso

```bash
python media_pile.py --pasta /caminho/para/midia --organizar --renomear --remover-duplicatas
```

## ⚙️ Configuração

Edite o arquivo `config.yaml` para definir regras de organização, padrões de nomenclatura e pastas de destino.
